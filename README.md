# MarkNote Studio (마크노트 스튜디오) 🍎✨

> **마크다운 문법을 몰라도, 애플(Apple) 감성으로 깔끔하고 직관적이게 작성하는 비주얼 마크다운 에디터**

---

## ✨ 주요 특징

1. **마크다운 문법 불필요 (완전한 WYSIWYG)**
   - 워드나 애플 메모처럼 글꼴, 글자 크기, 글자색, 형광펜, 표, 체크리스트를 클릭만으로 작성
   - 백그라운드에서 표준 GFM(GitHub Flavored Markdown) 규격으로 실시간 자동 변환

2. **완벽한 상하 계층 체계 (Tab / Shift+Tab 지원)**
   - `Tab`: 하위 단계로 들여쓰기 (글머리 기호, 번호 목록, 체크리스트의 하위 항목 생성 / 제목 H1~H6 단계 내리기)
   - `Shift+Tab`: 상위 단계로 내어쓰기 (상위 목록 복귀 / 제목 단계 올리기 / 본문으로 전환)
   - 툴바의 **[▸하위]**, **[◂상위]** 버튼으로도 마우스 클릭 지원

3. **고급 마크다운 꾸미기 요소 지원**
   - 접기/펼치기 아코디언 토글 블록 (`<details><summary>`)
   - GitHub 스타일 6종 알림 강조 박스 (`NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION` 등)
   - 키보드 단축키 배지 (`<kbd>Ctrl</kbd> + <kbd>S</kbd>`)
   - 위첨자, 아래첨자, 인라인 코드, 구분선

4. **한 화면에서 모든 정보 확인 (직관적 UI)**
   - 비주얼 위지윅 모드 / 실시간 분할 비교 모드 / 마크다운 원문 모드 1초 전환
   - 글자 수, 단어 수, 읽는 시간 실시간 통계 및 H1~H6 목차(TOC) 아웃라인

5. **다양한 실행 환경**
   - **설치형 (`.exe Setup`)**: 바탕화면 및 시작 메뉴 바로가기 생성, 백그라운드 자동 업데이트 지원
   - **무설치형 (`.exe Portable`)**: 설치 없이 USB나 원하는 폴더에서 바로 실행
   - **웹 단일 파일 (`독립실행형_마크다운편집기.html`)**: 크롬/엣지/사파리 등 브라우저에서 더블 클릭만으로 바로 사용

---

## 🚀 다운로드 및 설치

[GitHub Releases](https://github.com/kijung4290/marknote-studio/releases)에서 최신 버전을 다운로드하실 수 있습니다.

- **설치형**: `MarkNote Studio-Setup-1.0.0.exe`
- **무설치형**: `MarkNote Studio-Portable-1.0.0.exe`
- **웹 브라우저 단일 파일**: `독립실행형_마크다운편집기.html`

---

## 🔄 자동 업데이트 (Auto Update)

설치형 버전은 새 버전이 GitHub에 배포되면 자동으로 감지하여 백그라운드에서 다운로드하고 앱 재시작 시 자동으로 최신 버전으로 업데이트됩니다.
